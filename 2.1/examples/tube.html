Epithelial tube#

Relax an epithelial tube of 192 cells. A tube is one of the tissue topologies shown in Fig. 1f of Runser, Vetter & Iber (2024) (Citing SimuCell3D).

Files: parameters/core/parameters_tube.xml, data/input_meshes/fig_1_tube.vtk (192 epithelial cells).
Compile-time configuration: the defaults (POLARIZATION_MODE_INDEX 1, CONTACT_MODEL_INDEX 2, DYNAMIC_MODEL_INDEX 0).
Length: long. \(10^{-2}\) s of simulated time at a time step of 1e-7 s (100,000 iterations).
Measured run time: 3.69 hours with 2.1.0 on an 8-core cloud machine (GCP c2-standard-16, 8 threads), November 2026.

The parameter file#

parameters/core/parameters_tube.xml (numerical parameters)#
<numerical_parameters>
    <!-- The mesh file containing the initial configuration <! -->

    <input_mesh_file_path>/data/input_meshes/fig_1_tube.vtk</input_mesh_file_path> 

    <!-- The path where the mesh files will be written <! -->
    <output_mesh_folder_path>../simulation_results/simulation_tube</output_mesh_folder_path> 

    <!-- If equals 0 the cells will not be triangulated at the beginning of the simulation \<! -->
    <perform_initial_triangulation>1</perform_initial_triangulation> 

    <!-- If set to 1, the triangles with very high aspect ratio will be removed from the mesh \<! -->
    <!-- with the edge swap operation. \<!-->
    <enable_edge_swap_operation>0</enable_edge_swap_operation> 

    <!-- The damping coefficients [M / T] <! -->
    <damping_coefficient>5e-10</damping_coefficient> 

    <!-- The total simulation time [T] <! -->
    <simulation_duration>1e-2</simulation_duration> 

    <!-- The time between each mesh file saving [T]<! -->
    <sampling_period>1e-6</sampling_period> 

    <!-- The simulation time step [T]<! -->
    <time_step>1e-7</time_step> 

    <!-- The minimum edge length allowed [L] <! -->
    <min_edge_length>4e-7</min_edge_length> 

    <!-- The interaction cutoff distance above which cell-cell adhesions forces are 0[L]<! -->
    <contact_cutoff_adhesion>2.5e-7</contact_cutoff_adhesion> 

    <!-- The interaction cutoff distance above which cell-cell adhesions forces are 0[L]<! -->
    <contact_cutoff_repulsion>2.5e-7</contact_cutoff_repulsion> 
</numerical_parameters>

The file differs from Epithelial sheet only in the input mesh, the output folder, the damping coefficient (\(5\times10^{-10}\) kg/s instead of \(2\times10^{-9}\) kg/s) and the surface tension of the lateral faces (\(4\times10^{-4}\) N/m instead of \(5\times10^{-4}\) N/m). All cells of the mesh use the epithelial cell type, which neither grows nor divides. The input cells are triangulated at the start of the run.

Run#

From the build/ directory:

$ ./simucell3d ../parameters/core/parameters_tube.xml

The output folder is simulation_results/simulation_tube/ in the repository root; it is deleted at the start of the run. As for the sheet, the run writes \(10^4\) pairs of mesh files, and the mesh path starting with /data/ is resolved relative to the source directory after a warning.

What to expect#

The November 2026 benchmark ran this file with 2.1.0 on an 8-core cloud machine (GCP c2-standard-16, 8 threads), one run, with a sampling period of \(10^{-4}\) s instead of \(10^{-6}\) s (output only):

  • The 100,000 iterations took 3.69 hours (1.0 with two crash fixes: 6.29 hours), and no cell was removed.

  • The tube relaxes without growing: it shortens by 19-24%, its lumen closes so that cells fill the cross-section, and the cells end at a pressure of 284-286 Pa with about 10.5 contact neighbours each. This is the same in every version tested, 1.0 included, to within the run-to-run spread.

What to look at#

Open cell_data/result_*.vtk in ParaView and colour by cell_pressure; open face_data/result_*.vtk and colour by face_type_id to see the apical and lateral labels assigned from cell contacts. As for the sheet, the basal face type and adherence_strength of the file have no effect in the default build (Compile-time configuration).
