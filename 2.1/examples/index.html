Examples#

Each example runs one of the parameter files shipped in parameters/, states the compile-time configuration it needs, and describes what to look at in the output. All commands are run from the build/ directory of a Release build (Installing SimuCell3D), unless stated otherwise.

The length of a run depends on the number of iterations (simulated time divided by the time step), the number of cells and the resolution of their meshes. Short runs take minutes, long runs hours to days on a workstation.
