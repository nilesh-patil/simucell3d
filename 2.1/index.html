SimuCell3D#

SimuCell3D simulates the mechanics of three-dimensional tissues at subcellular resolution. Each cell is a deformable cell model (DCM): a closed, triangulated surface whose shape follows from its volume, surface tension, area elasticity and bending energy, and from adhesion and repulsion at contacts with neighbouring cells. Faces of a cell carry a face type (for example apical, lateral or basal), so that cell polarization can be modelled with face-dependent mechanical properties. Besides epithelial cells, a tissue can contain nuclei, extracellular matrix (ECM), lumens and static obstacles. Cells grow, divide and are removed during a run. The simulator is a C++17 command-line program parallelized with OpenMP; an optional Python module drives the same solver.

SimuCell3D was created by Steve Runser in the Iber Lab (D-BSSE, ETH Zurich, and the Swiss Institute of Bioinformatics) and is described in Runser, Vetter & Iber (2024), Nature Computational Science (Citing SimuCell3D); the concept is by Roman Vetter and Dagmar Iber (About SimuCell3D). This documentation covers the 2.x maintenance releases, maintained by Nilesh Patil and not reviewed or endorsed by the authors of the article, the Iber Lab or ETH Zurich.

Important

Results differ from 1.0. A simulation run with SimuCell3D 2.1 does not reproduce the numbers produced by 1.0, the code published with the paper. Several 1.0 bugs changed the physics, and fixing them changes trajectories; 2.1 also adds safeguards that remove or repair cells that 1.0 would have kept; a run can lose many cells this way and still exit with status 0 (Safeguards). To compare with the published figures, run release 1.0; note that the tag v1.0 and the Zenodo archive cited by the paper differ in their default contact model (Release 1.0). See Release 2.1.

Install

Build simucell3d from source with CMake, or run it in Docker. Optional Python bindings.
