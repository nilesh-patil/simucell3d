SimuCell3D#

SimuCell3D simulates the mechanics of three-dimensional tissues at subcellular resolution, with every cell a deformable, triangulated surface.

Quick start#

  1. Build simucell3d in Release mode on Linux (Installing SimuCell3D lists the requirements and the Docker alternative).

    $ git clone https://github.com/nilesh-patil/simucell3d.git
$ cd simucell3d
$ mkdir build
$ cd build
$ cmake -DCMAKE_BUILD_TYPE=Release ..
$ make -j4

  2. Run the short vesicle simulation from build/ (200 iterations, a few minutes). Its output folder, simulation_results/simulation_vesicle/, is deleted at the start of every run.

    $ ./simucell3d ../parameters/core/parameters_vesicle_quick.xml

  3. Open the output in ParaView: File > Open, go to simulation_results/simulation_vesicle/cell_data/, select the group result_..vtk, click OK and then Apply. Getting started explains the output and changes a parameter.

Note

Results of 2.1 differ from 1.0 because 1.0 defects that changed the physics are fixed (Release 2.1). Safeguards can remove cells, and a run can still exit with status 0 (Safeguards). To compare with the published figures, use release 1.0 (Release 1.0).

About this software#

SimuCell3D was created by Steve Runser in the Iber Lab (D-BSSE, ETH Zurich, and the Swiss Institute of Bioinformatics) and is described in Runser, Vetter & Iber (2024), Nature Computational Science (Citing SimuCell3D); the concept is by Roman Vetter and Dagmar Iber (About SimuCell3D). This documentation covers the 2.x maintenance releases, maintained by Nilesh Patil and not reviewed or endorsed by the authors of the article, the Iber Lab or ETH Zurich.

Citing#

If SimuCell3D contributes to a publication, cite the paper:

Runser, S., Vetter, R. & Iber, D. SimuCell3D: three-dimensional simulation of tissue mechanics with cell polarization. Nat. Comput. Sci. 4, 299-309 (2024). https://doi.org/10.1038/s43588-024-00620-9
