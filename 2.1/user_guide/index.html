User guide#

The user guide explains the model that SimuCell3D simulates and how to run and analyse simulations. Chapters 1 to 10 describe the model: the mechanics of a cell, contact between cells, time integration, mesh maintenance, growth and division, polarization, the cell classes, the safeguards added in 2.1 and the compile-time options. Chapters 11 to 18 describe the parameter file, input meshes, running simulations, output files, visualisation, the Python interface, parameter screening and parallel performance.

The equations follow the Methods of Runser, Vetter & Iber (2024) and its Supplementary Information. Where the 2.1 code differs from the paper, the chapters say so in a note.

Model. Read in order for an understanding of what a simulation computes:

  1. Model overview: cells as closed triangulated surfaces, cell types, cell classes and face types, the solver loop, compile-time and run-time choices.

  2. Cell mechanics: the cell energy, pressure, surface tension, area elasticity, bending and their nodal forces.

  3. Contact between cells: the three contact models, contact detection and the coupling of nodes.

  4. Time integration: the dynamic and overdamped equations of motion, the time step and output intervals.

  5. Mesh refinement: edge-length bounds, split, collapse and swap, the initial triangulation.

  6. Growth, division and removal: growth of the target volume, division along the longest axis, refused divisions, removal.

  7. Polarization: face types and how the polarization modes assign them.

  8. Cell classes: epithelial, ECM, lumen, nucleus and static cells.

  9. Safeguards: what 2.1 does with damaged or diverged cells, and how to count it.

  10. Compile-time configuration: the configuration header and how to rebuild.

Running and analysing simulations. Read as needed:

  1. Parameter file reference: every tag of the XML parameter file.

  2. Input meshes: the input mesh format and how to build meshes.

  3. Running simulations: command-line options, paths and long runs.

  4. Output files: mesh files, the statistics CSV and the diagnostics CSV.

  5. Visualization: viewing results in ParaView and plotting statistics.

  6. Python interface: running simulations from Python.

  7. Parameter screening: running parameter screens on a cluster.

  8. Parallel performance: threads, scheduling and the cost of large tissues.

Readers who want to run a first simulation before reading the model chapters can start with Getting started and the Examples. Terms are defined in the Glossary.
