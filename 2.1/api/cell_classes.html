Cell classes#

Each <cell_type> block of the parameter file selects one of five classes through its global_cell_id: 0 epithelial_cell, 1 ecm_cell, 2 lumen_cell, 3 nucleus_cell, 4 static_cell (src/io/simulation_initializer.cpp). Each class derives from cell and overrides the parts of the mechanics or the polarization that differ for that kind of cell. The narrative description is in Cell classes.

The class of a cell decides what it does in the steps of an iteration that call virtual members of cell: the face-type update, the contact-based polarization, the internal forces, the division check, and whether the time integration moves it.

face_area_pair_hasher and face_area_pair_comparator are helper functors of epithelial_cell. ECM and static cells are static cells in the sense of is_static_: the time integration skips them, and cell::check_numerical_stability() does not test them for a negative volume or a volume larger than their bounding box. To add a class, see Architecture.

Classes#

class epithelial_cell : public cell#

Epithelial cell, selected by global_cell_id 0.

The only cell class that divides: is_ready_to_divide() is true once the volume reaches the division volume drawn at creation. Its faces are polarized by contacts. Face types are indices into the cell type’s face types and are used as 0 apical, 1 lateral, 2 basal, so an epithelial cell type is expected to list its face types in that order.

At every iteration update_face_types() marks all faces apical. Then, with POLARIZATION_MODE_INDEX 1:

  • with contact model 0, the contact model calls face_is_in_contact() for each face in contact (basal next to an ECM cell, apical next to a lumen, lateral otherwise);

  • with contact models 1 and 2, special_polarization_update() marks a face lateral when its three nodes are coupled to nodes of one other cell that form an edge triangle (model 1) or a face (model 2) of that cell.

inline virtual void face_is_in_contact(const unsigned face_local_id, const cell_ptr other_cell) noexcept override#

Set the type of face face_local_id from the class of the cell it touches.

ECM (global_cell_id 1) gives basal (2), lumen (2) gives apical (0), any other gives lateral (1). Called by contact model 0 when POLARIZATION_MODE_INDEX is 1.

inline virtual void special_polarization_update(const std::vector<cell_ptr> &cell_lst) noexcept override#

Mark as lateral (1) the faces coupled to a face of one neighbouring cell, the others apical (0).

A face is lateral when its three nodes are coupled to nodes of a single other cell and those nodes form a face (contact model 2) or three edges (contact model 1) of that cell.

Note

Does nothing unless POLARIZATION_MODE_INDEX is 1 and CONTACT_MODEL_INDEX is 1 or 2. Reads the node couplings without locks; call it after the contact phase.

inline virtual void update_face_types() noexcept override#

Reset every face to apical (0); called at the start of each iteration.

inline virtual double get_contact_area_fraction() override#

Return the area of the lateral faces (type 1) divided by the cell area.

class ecm_cell : public cell#

Extracellular matrix (ECM) cell, selected by global_cell_id 1.

An ECM cell is static: it does not move (the time integration skips it) and its internal forces are not computed (apply_internal_forces() does nothing). It still takes part in contact detection. With contact model 0 and contact-based polarization (POLARIZATION_MODE_INDEX 1), epithelial faces in contact with an ECM cell become basal. ECM cells do not divide.

class lumen_cell : public cell#

Lumen cell, selected by global_cell_id 2.

A lumen is a deformable cell with the mechanics of the base class cell and no overrides other than get_cell_same_type(). With contact model 0 and contact-based polarization (POLARIZATION_MODE_INDEX 1), epithelial faces in contact with a lumen become apical. Lumen cells do not divide.

class static_cell : public cell#

Static cell, selected by global_cell_id 4.

A static cell does not move: the time integration skips it. Unlike ecm_cell, its internal forces are still computed, and it takes part in contact detection. Static cells do not divide and are not checked for inside-out or self-intersecting surfaces by cell::check_numerical_stability().
