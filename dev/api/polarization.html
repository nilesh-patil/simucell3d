Polarization#

With POLARIZATION_MODE_INDEX 2, the solver uses automatic_polarizer to assign face types from a discretisation of the simulation space, and automatic_polarization_writer writes the resulting regions to region_data/. With POLARIZATION_MODE_INDEX 1 (default), polarization is based on cell contacts and is implemented in the cell classes, mainly epithelial_cell. The narrative description is in Polarization.

In an iteration, automatic_polarizer::polarize_faces() runs after contact detection and before the internal forces. The writer is called with every mesh output after iteration 1, so the meshes written at the start of the run have no region_data/ file.

Classes#

class automatic_polarizer#

Assigns face types to epithelial cells from a voxel discretization of the space.

Used by the solver when POLARIZATION_MODE_INDEX is 2. At each call of polarize_faces():

  1. A uspg_3d grid of voxel edge max_edge_length covers the nodes plus two voxels of margin.

  2. Voxels that contain a node are labelled boundary.

  3. From the voxel of each cell centroid, the cytoplasm label is flood-filled (6-connected) up to the boundary voxels.

  4. From the corner voxel (0, 0, 0), the exterior label is flood-filled the same way.

  5. The remaining unlabelled voxels are labelled lumen.

  6. For each face of each epithelial cell (cell class 0), a ray is cast from its first node along the face normal; the first non-boundary voxel gives the region in contact. Faces facing the exterior get face type 0; faces facing a lumen or another cell get face type 1 (indices into the face types of the cell type).

Note

The cytoplasm fill starts at the centroid, so it fails for a cell whose centroid lies outside its volume (strongly concave cells).

class automatic_polarization_writer#

Writes the voxel grid of an automatic_polarizer to a legacy VTK file.

With POLARIZATION_MODE_INDEX 2, the solver calls write() each time it writes the output meshes after the first iteration, into <output>/region_data/result_<n>.vtk. Each voxel is written as a cube with the cell array voxel_type_id: -1 unlabelled, 0 boundary, 1 cytoplasm, 2 exterior space, 3 lumen.
