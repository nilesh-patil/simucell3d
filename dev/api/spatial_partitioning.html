Spatial partitioning#

A uniform spatial partitioning grid (USPG) sorts objects into cubic voxels so that a neighbour search only visits nearby voxels. uspg_4d stores any number of objects per voxel and is used by contact models 0 and 1, by the Poisson sampling and ball pivoting of the initial triangulation, by the point sampling of a division interface, and by contact_detection_uspg_strategy; uspg_3d stores at most one object per voxel and is used by the automatic polarizer. morton_code computes Morton (Z-order) codes; it is used by contact_detection_uspg_strategy to sort faces by position before inserting them. Contact model 2 does not use these classes during a run: it bins faces in its own compact grid (contact_face_face_via_coupling).

The grid is rebuilt from the current face bounding boxes at every contact detection, so its size follows the extent of the tissue. A cell whose nodes diverge would make that extent, and the number of voxels, grow without bound; the grids refuse such a domain and the solver removes diverged cells before they reach contact detection (Safeguards).

Grids#

class uspg_abstract#

Base class of the uniform spatial partitioning grids (USPG).

A USPG divides an axis-aligned box into cubic voxels of equal edge length, so that a neighbour search only visits the voxels near a point (C. Ericson, Real-Time Collision Detection, section 7.1). Voxels are stored in a flat array indexed x + y n_x + z n_x n_y. The derived classes define what a voxel holds: uspg_4d any number of objects, uspg_3d at most one.

Subclassed by uspg_3d< unsigned short >, uspg_4d< oriented_point >, uspg_4d< face * >, uspg_3d< T >, uspg_4d< T >

class morton_code#

Morton (Z-order curve) encoding of 3D positions.

Each coordinate is quantized to 21 bits and the bits are interleaved into a 63-bit code: x bits go to positions 0, 3, 6, …, y bits to 1, 4, 7, …, z bits to 2, 5, 8, …. Sorting objects by their code places nearby objects close together in memory. The USPG contact detection strategy sorts faces this way before inserting them into its grid.

Public Static Functions

Return the Morton code of a point given in normalized coordinates.

Parameters:

nx, ny, nz – Coordinates in [0, 1]; values outside are clamped. Each is quantized to 21 bits.

Returns:

The 63-bit interleaved code.

Return the Morton code of a position within a box.

  • bounds – Box as six values {min_x, min_y, min_z, max_x, max_y, max_z}, m. An axis of zero extent maps to coordinate 0.
