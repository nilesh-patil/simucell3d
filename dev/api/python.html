Python module#

Reference for the pybind11 module simucell3d_python_wrapper, defined in src/python_bindings/simucell3d_wrapper.cpp. The module exposes the parameter structures, a class that runs a complete simulation, and read-only access to the cells at the end of the run. How to build and use it, with the mapping of each attribute to its XML tag, is described in Python interface; a complete script is scripts/python_bindings/launch_simulation_example.py.

Building and importing#

The module is built only when CMake is configured with -DENABLE_PYTHON_BINDINGS=TRUE (default FALSE). From the repository root:

$ cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DENABLE_PYTHON_BINDINGS=TRUE
$ cmake --build build -j

The shared library is written to build/bin/python_bindings/ as simucell3d_python_wrapper.cpython-<version>-<platform>.so. It is not installed; add that directory to sys.path (or PYTHONPATH) before importing:

import sys
sys.path.insert(0, "build/bin/python_bindings")
import simucell3d_python_wrapper as sc

Note

The Python module is not built by the continuous integration workflows.

Running a simulation#

outputs = sc.simucell3d_wrapper(sim_params, [cell_type], True, -1).get_simulation_outputs()
if outputs.RETURN_CODE_ == 0:
    print(outputs.cell_statistics_.splitlines()[0])
else:
    print(outputs.error_message_)

The constructor of simucell3d_wrapper performs the whole simulation: it creates the cells from the input mesh and the cell types, runs the solver until simulation_duration_, and stores the result. Errors do not raise Python exceptions; they set RETURN_CODE_ and error_message_. Pressing Ctrl-C stops the run at the start of the next iteration and is reported the same way.

Differences from a run of the simucell3d executable:

  • The contact detection algorithm cannot be chosen: Python runs always use the uniform spatial partitioning grid (USPG).

  • Per-cell statistics are returned in simulation_outputs.cell_statistics_ instead of being written to simulation_statistics.csv. The output meshes (cell_data/, face_data/) and performance_diagnostics.csv are still written to output_folder_path_, and that folder is deleted at the start of the run.

  • The OpenMP scheduling mode is the solver default (adaptive).

  • Thread pinning applies to the calling Python thread as well: after the run it stays pinned to one CPU (check with os.sched_getaffinity(0)). Set SIMUCELL3D_PIN_THREADS=0 before the run to avoid this.

Classes#

Attribute names end with an underscore, as the C++ members do. All parameter classes have a constructor without arguments; set attributes one by one after construction. Units are SI.

class simucell3d_python_wrapper.global_simulation_parameters#

Numerical parameters of a simulation. Equivalent to the numerical section of the parameter file (Parameter file reference); C++ type global_simulation_parameters.

output_folder_path_: str#

Folder for the output files. Deleted and re-created at the start of the run. A relative path is relative to the working directory of the Python process.

input_mesh_path_: str#

Input mesh (legacy VTK). Tried as given, then relative to the source directory recorded at configure time.

damping_coefficient_: float#

Damping coefficient, kg/s.

simulation_duration_: float#

Simulated time, s.

sampling_period_: float#

Simulated time between two output meshes, s.

time_step_: float#

Time step, s.

min_edge_len_: float#

Minimum edge length of the cell meshes, m. The maximum edge length is three times this value.

contact_cutoff_adhesion_: float#

Distance beyond which adhesion forces are zero, m.

contact_cutoff_repulsion_: float#

Distance beyond which repulsion forces are zero, m.

perform_initial_triangulation_: bool#

Re-triangulate the input meshes before the run. Default True.

enable_edge_swap_operation_: bool#

Allow the local mesh refiner to swap the longest edge of triangles with a high aspect ratio. Default True.

class simucell3d_python_wrapper.cell_type_parameters#

Parameters of one cell type, equivalent to a <cell_type> block of the parameter file; C++ type cell_type_parameters. The position of a cell type in the list passed to simucell3d_wrapper is the cell_type_id used in the input mesh.

name_: str#
global_type_id_: int#

Cell class: 0 epithelial, 1 ECM, 2 lumen, 3 nucleus, 4 static. Default 0.

mass_density_: float#

Mass density, kg/m^3. Default 0.

bulk_modulus_: float#

Bulk modulus \(K\), Pa. Default 1.

max_pressure_: float#

Upper bound of the pressure difference between the cell and its surroundings, Pa. Default 0.

initial_pressure_: float#

Pressure at the start of the run, Pa. The initial target volume is set to \(V \exp(p_0/K)\), where \(V\) is the volume of the input mesh (or \(V\) when \(K = 0\)). Not available in the XML parameter file, where it is always 0. Default 0.

area_elasticity_modulus_: float#

Area elasticity modulus \(k_a\), J. Default 0.

avg_division_vol_: float#

Mean of the normal distribution from which each cell draws its division volume, m^3. Default 0.

std_division_vol_: float#

Standard deviation of the division volume, m^3. Default 0.

avg_growth_rate_: float#

Mean of the normal distribution from which each cell draws its growth rate, m^3/s. Default 0.

std_growth_rate_: float#

Standard deviation of the growth rate, m^3/s. Default 0.

angle_regularization_factor_: float#

Strength of the force that keeps triangle angles close to 60 degrees. Default 0.

target_isoperimetric_ratio_: float#

Target isoperimetric ratio \(A^3/V^2\), dimensionless. Default 0.

min_vol_: float#

Volume below which the cell is removed, m^3. Default 0.

surface_coupling_max_curvature_: float#

Curvature above which a node is not coupled to a neighbouring cell, 1/m. Default 0.

add_face_type(face_type)#

Append a face_type_parameters to this cell type. Face types are stored in the order they are added and cannot be read back from Python.

add_additional_parameter(name, value)#

Store a named floating-point parameter in the cell type (str, float). The value is stored but no part of the 2.1 solver reads it.

class simucell3d_python_wrapper.face_type_parameters#

Parameters of one face type, equivalent to a <face_type> block; C++ type face_type_parameters.

name_: str#
face_type_global_id_: int#

Identifier of the face type written to the output meshes. Default 0.

surface_tension_: float#

Surface tension \(\gamma\), N/m. Default 0.

adherence_strength_: float#

Adherence strength \(\omega\), N/m^3. Default 0.

repulsion_strength_: float#

Repulsion strength \(\xi\), N/m^3. Has no default; always set it.

bending_modulus_: float#

Bending modulus \(k_b\), J. Default 0.

class simucell3d_python_wrapper.simucell3d_wrapper(sim_parameters, cell_types, verbose, nb_threads)#

Run a complete simulation in the constructor.

The four arguments are positional and required; keyword arguments are not accepted.

Parameters:

  • sim_parameters (global_simulation_parameters) – Numerical parameters.

  • cell_types (list[cell_type_parameters]) – Cell types, indexed by the cell_type_id of the input mesh.

  • verbose (bool) – Print the progress of the simulation.

  • nb_threads (int) – Number of OpenMP threads. A value of 0 or less uses one thread per physical core.

get_simulation_outputs()#

Return a copy of the result of the run.

Return type:

simulation_outputs

class simucell3d_python_wrapper.simulation_outputs#

Result of a run; C++ type simulation_outputs.

RETURN_CODE_: bool#

False (equal to 0) if the run completed, True (equal to 1) if an exception stopped it.

error_message_: str#

Message of the exception that stopped the run; empty on success.

cell_statistics_: str#

Per-cell statistics in CSV format, with the same columns as simulation_statistics.csv (Output files): one row per cell every 50 iterations. Empty if the run failed.

cell_lst_: list[cell]#

The cells at the end of the run. Empty if the run failed.

class simucell3d_python_wrapper.cell#

A cell at the end of a run, from simulation_outputs.cell_lst_. It cannot be constructed from Python. C++ type cell.

get_id()#

Identifier of the cell (int).

get_cell_type_id()#

global_type_id_ of the cell type (int).

get_growth_rate()#

Growth rate of the target volume, m^3/s.

get_area()#

Surface area, m^2.

get_volume()#

Volume, m^3.

get_pressure()#

Pressure, Pa.

get_target_volume()#

Target volume \(V_0\), m^3.

get_node_coord_lst()#

Node coordinates as a list of [x, y, z] lists, m.

get_face_point_ids()#

Faces as a list of [i, j, k] lists of indices into get_node_coord_lst().
