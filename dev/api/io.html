Input and output#

These classes read the parameter file and the input mesh, create the cells, and write the output meshes and statistics. parameter_reader parses the XML parameter file (Parameter file reference); mesh_reader reads the legacy VTK input mesh (Input meshes); simulation_initializer combines both into the list of cells passed to the solver. During the run, mesh_writer writes the cell and face meshes, and a statistics writer writes one row per cell per sample, either to simulation_statistics.csv (csv_file_statistics_writer) or to a string (string_statistics_writer, used by the Python module). The arrays written to the output meshes are defined by the data mappers in mesh_data.hpp; adding a mapper there adds an array to every output file (Output files).

Reading input#

class parameter_reader#

Reads the XML parameter file into global_simulation_parameters and cell_type_parameters.

The file has a <numerical_parameters> section and a <cell_types> section with one <cell_type> block per cell type, each holding a <face_types> list of <face_type> blocks. Tag names are documented with the members of the parameter structures.

class simulation_initializer#

Builds the list of cells and the numerical parameters passed to the solver.

Reads the parameter file (or takes the parameter structures directly), reads the input mesh, triangulates each cell surface in parallel and creates, for each cell, an object of the class selected by the global_type_id_ of its cell type: 0 epithelial_cell, 1 ecm_cell, 2 lumen_cell, 3 nucleus_cell, 4 static_cell. The cell_type_id of a cell in the input mesh is the position of its cell type in the parameter file.

Create one cell from its input mesh, retrying up to 10 times.

With perform_initial_triangulation the surface is re-triangulated with edge lengths between the minimum edge length and three times that value; otherwise the input faces must already be triangles.

Writing output#

class mesh_writer#

Writes the cell and face meshes as legacy ASCII VTK files (version 4.2, unstructured grid).

The cell mesh has one polyhedron (VTK type 42) per cell with the arrays of cell_data_mapper_lst; the face mesh has one triangle (VTK type 7) per face with the arrays of face_data_mapper_lst and node_data_mapper_lst (mesh_data.hpp). All members are static; the class cannot be instantiated.

The cells are rebased first (unused node and face slots removed); the two files are written in parallel.

Lists of data mappers that define the arrays of the output meshes and the columns of the statistics.

Each mapper names an array (or column), its VTK type and a function that formats the value of one cell, face or node as a string. Adding a mapper to a list adds the array to every output file:

  • cell_data_mapper_lst: cell-data arrays of cell_data/result_<n>.vtk;

  • file_data_mapper_lst: columns of simulation_statistics.csv (and of the statistics string returned to Python), after iteration, computation_time_(hh::mm:ss) and simulation_time;

  • face_data_mapper_lst: cell-data arrays of face_data/result_<n>.vtk (one VTK cell per face);

  • node_data_mapper_lst: point-data arrays of face_data/result_<n>.vtk (only with CONTACT_MODEL_INDEX 2).

std::vector<face_data_mapper> face_data_mapper_lst#

std::vector<node_data_mapper> node_data_mapper_lst#
