Release 1.0#

Release 1.0.0 (Zenodo archive 2024-03-08; tag v1.0 2024-06-26)

The code published with Runser, Vetter & Iber (2024), “SimuCell3D: three-dimensional simulation of tissue mechanics with cell polarization”, Nature Computational Science 4, 299-309 (doi:10.1038/s43588-024-00620-9). The project was then called DCM.

Use 1.0 to reproduce or compare with the figures of the paper: later releases change simulation results (Release 2.1).

Obtaining 1.0#

Two snapshots of the 1.0 code exist, and they are not identical:

Zenodo archive

Tag v1.0

Identifier

doi:10.5281/zenodo.10796908, cited by the paper (its ref. 76)

git tag v1.0 of this repository, the head of the Iber Lab repository

Commit

5342bf8 (2024-03-07; archive published 2024-03-08)

38af451 (2024-06-26), a later commit by the same author

Default CONTACT_MODEL_INDEX

1 (node-node coupling, described in the paper)

2 (face-face coupling, not described in the paper)

Input files of Figs. 1 and 3

not included

fig_1_*.vtk, fig_3_vesicle.vtk, parameters_vesicle.xml, parameters_sheet.xml, parameters_tube.xml

The source files in src/ are the same in both. It is not documented which contact model produced each published figure; the input files added in 38af451 are written for model 2. When you compare with a published figure, record which snapshot and which CONTACT_MODEL_INDEX you used. The raw data of the paper are archived separately, doi:10.5281/zenodo.10797576.

$ git clone https://github.com/nilesh-patil/simucell3d.git
$ cd simucell3d
$ git checkout v1.0      # the tag; or: git checkout 5342bf8 for the archived commit

Building and running 1.0#

Release 1.0 has the same requirements as 2.1 except that it accepts older CMake versions; it was checked with CMake 3.18 and GCC 10. CMake 4 refuses its cmake_minimum_required(VERSION 3.0); with CMake 4, add -DCMAKE_POLICY_VERSION_MINIMUM=3.5 to the cmake line. From the repository root (the last line needs the tag, because the archive has no parameters_vesicle.xml):

$ mkdir build
$ cd build
$ cmake -DCMAKE_BUILD_TYPE=Release ..
$ make -j4
$ ./simucell3d ../parameters_vesicle.xml

Differences from 2.1 that affect command lines and scripts:

  • The parameter files are in the repository root (parameters_vesicle.xml, parameters_default_dynamic.xml, …), not in parameters/core/.

  • The executable takes exactly one argument, the parameter file. The options --schedule, --threads, --output-dir, --diagnostics-csv and --version do not exist; no performance_diagnostics.csv is written.

  • The compile-time options in include/global_configuration.hpp have the same names (POLARIZATION_MODE_INDEX, CONTACT_MODEL_INDEX, DYNAMIC_MODEL_INDEX).

The 1.0 documentation is the README.md and doc/ folder of the tag.
