Release 2.0#

Release 2.0.0 (2026-03-02)

First maintenance release of SimuCell3D after the published 1.0 code. Its changes are also described, together with the 2.1 changes, in Release 2.1, where items from 2.0 are marked (2.0).

Important

2.0 already changes simulation results compared with 1.0, because of the two correctness fixes listed below.

Changes#

  • The project was renamed from DCM to SimuCell3D, and the source layout and build were reorganised.

  • Adaptive OpenMP scheduling, selected with --schedule.

  • A faster spatial grid (USPG): vector storage of the voxels, ordered along a Morton curve.

  • Optional sweep-and-prune contact detection (<contact_detection_algorithm> in the parameter file).

  • A per-iteration diagnostics CSV (--diagnostics-csv=PATH).

  • First correctness fixes, which change results compared with 1.0: the closest-point error in the contact distance to a face interior, and the semi-implicit Euler step (with contact model 2, 1.0 had moved every node with a forward Euler step).

  • Memory-safety and robustness fixes: a heap use-after-free in edge splits, division-by-zero guards, an integer overflow in the spatial grid, and an oscillation bail-out in the mesh refiner.

  • GitHub Actions continuous integration with sanitizer builds and benchmark workflows. The test suite grew to 294 registered CTest targets.

Obtaining 2.0#

The release is the git tag v2.0:

$ git clone https://github.com/nilesh-patil/simucell3d.git
$ cd simucell3d
$ git checkout v2.0

It builds with the same commands as 2.1 (Installing SimuCell3D).
