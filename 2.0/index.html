SimuCell3D

SimuCell3D was created by Steve Runser, Roman Vetter and Dagmar Iber (Iber Lab, ETH Zurich). The 2.x releases are maintained by Nilesh Patil on a fork and are not reviewed or endorsed by the authors.

The pages below are the Markdown documentation in tag v2.0: the README.md, the doc/ folder, the README files of examples/, scripts/, src/mesh/ and baselines/, and the plans in docs/plans/. The root files INSTALL.md, GETTING_STARTED.md, FAQ.md and CONTRIBUTING.md are symbolic links to pages of doc/getting-started/ and are not repeated. The tag also contains two PDF copies of the article and its supplement (doc/SimuCell3D.pdf, doc/SimuCell3D-extra.pdf); they are not published here, and links to them go to the article’s DOI. The release notes of 2.0 summarise the changes from 1.0.

Corrections#

Warning

Read this before you rely on these pages. The following was found after the release. The original text below is left as it was.

  • Citation. The README cites the article as “Runser, Adrien and others”. The correct citation is: Runser, S., Vetter, R. & Iber, D. SimuCell3D: three-dimensional simulation of tissue mechanics with cell polarization. Nat. Comput. Sci. 4, 299-309 (2024). doi:10.1038/s43588-024-00620-9.

  • “Full backward compatibility”, “no new scientific features”, “all v1.0 commands work without modification”. These statements are wrong. 2.0 changes simulation results compared with 1.0, because it fixes the contact distance to a face interior and the time integration of contact model 2. The parameter files moved from the repository root to parameters/, and the lab’s growth benchmark file of 1.0, parameters_benchmarck.xml, was removed without a note. Do not use 2.0 to reproduce the published figures; use 1.0 (the Zenodo archive doi:10.5281/zenodo.10796908 cited by the article).

  • Build badge. The “build passing” badge in the README was a static image, not live CI status.

  • Growth runs fail early. In the November 2026 benchmark (8-core cloud machines), no 2.0 run of the lab’s growth benchmark grew past 216 cells, and the shipped long monolayer vesicle file crashed. See which cases complete in the current documentation.

  • Licence file. The LICENSE file of 2.0 added a copyright line that release 1.0 does not have. Release 2.1.0 restored the licence text of 1.0 and states the authorship in NOTICE (see licence and notice).

These corrections are also recorded in the GitHub release notes of 2.0 and in the changelog.

Obtaining and building 2.0#

$ git clone https://github.com/nilesh-patil/simucell3d.git
$ cd simucell3d
$ git checkout v2.0
$ mkdir build
$ cd build
$ cmake -DCMAKE_BUILD_TYPE=Release ..
$ make -j4
$ ./simucell3d ../parameters/core/parameters_vesicle.xml

Release 2.0 needs a C++17 compiler with OpenMP and CMake. Like 1.0 it declares cmake_minimum_required(VERSION 3.0), which CMake 4 refuses; with CMake 4, add -DCMAKE_POLICY_VERSION_MINIMUM=3.5 to the cmake line. The quick-start page of 2.0 says cd SimuCell3D after the clone; the clone creates the directory simucell3d. The option --version does not exist in 2.0.
