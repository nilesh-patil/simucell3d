Short vesicle run#

Run 200 iterations of the vesicle of Epithelial vesicle with lumen and ECM, as a check that a build works and as the first simulation of Getting started.

Files: parameters/core/parameters_vesicle_quick.xml, data/input_meshes/fig_3_vesicle.vtk (434 cells: 432 epithelial cells, one ECM surface, one lumen).
Compile-time configuration: the defaults (POLARIZATION_MODE_INDEX 1, CONTACT_MODEL_INDEX 2, DYNAMIC_MODEL_INDEX 0).
Length: short. \(2\times10^{-5}\) s of simulated time at a time step of 1e-7 s (200 iterations).
Measured run time: 1 min 48 s with 2.1.0 on a 4-core cloud machine (GCP c2-standard-8, 4 threads), November 2026; not part of the benchmark.

The parameter file#

The file is parameters/core/parameters_vesicle.xml with a shorter simulated time (\(2\times10^{-5}\) s instead of \(10^{-2}\) s) and a longer sampling period (\(5\times10^{-6}\) s instead of \(10^{-6}\) s). All mechanical parameters are the same; they are listed in Epithelial vesicle with lumen and ECM.

parameters/core/parameters_vesicle_quick.xml (numerical parameters)#
<numerical_parameters>
    <!-- The mesh file containing the initial configuration -->
    <input_mesh_file_path>data/input_meshes/fig_3_vesicle.vtk</input_mesh_file_path>

    <!-- The path where the mesh files will be written -->
    <output_mesh_folder_path>../simulation_results/simulation_vesicle</output_mesh_folder_path>

    <!-- If equals 0 the cells will not be triangulated at the beginning of the simulation -->
    <perform_initial_triangulation>0</perform_initial_triangulation>

    <!-- If set to 1, the triangles with very high aspect ratio will be removed from the mesh -->
    <enable_edge_swap_operation>0</enable_edge_swap_operation>

    <!-- The damping coefficients [M / T] -->
    <damping_coefficient>5e-10</damping_coefficient>

    <!-- The total simulation time [T]. Quick test: 2e-5 s = 200 time steps (parameters_vesicle.xml: 1e-2 s) -->
    <simulation_duration>2e-5</simulation_duration>

    <!-- The time between each mesh file saving [T] -->
    <sampling_period>5e-6</sampling_period>

    <!-- The simulation time step [T]. Same as parameters_vesicle.xml; larger steps make this mesh unstable -->
    <time_step>1e-7</time_step>

    <!-- The minimum edge length allowed [L] -->
    <min_edge_length>4e-7</min_edge_length>

    <!-- The interaction cutoff distance above which cell-cell adhesions forces are 0[L] -->
    <contact_cutoff_adhesion>2e-7</contact_cutoff_adhesion>

    <!-- The interaction cutoff distance above which cell-cell adhesions forces are 0[L] -->
    <contact_cutoff_repulsion>2e-7</contact_cutoff_repulsion>
</numerical_parameters>

Run#

From the build/ directory:

$ ./simucell3d ../parameters/core/parameters_vesicle_quick.xml

The output folder is simulation_results/simulation_vesicle/ in the repository root, the same as for Epithelial vesicle with lumen and ECM; it is deleted at the start of the run. The warning that the mesh path data/input_meshes/fig_3_vesicle.vtk was not found, followed by the path relative to the source directory, is expected when running from build/. The run takes about two minutes on 4 cores and writes about 290 MB of mesh files.

What to look at#

  • cell_data/result_1.vtk to result_4.vtk and the matching face_data/ files: the tissue every \(5\times10^{-6}\) s, starting at \(t = 0\). In ParaView, colour the cell meshes by cell_type_id or cell_pressure (Getting started).

  • simulation_statistics.csv: one row per cell at iterations 0, 50, 100, 150 and 200; the number of distinct cell_id values stays at 434.

  • performance_diagnostics.csv: one row, at iteration 100. Its unstable_cells_removed column is 0, and the standard error output contains no Removing numerically unstable cell lines.

Note

The time step cannot be raised to shorten the run. With a time step of 5e-7 s this vesicle becomes unstable at once. In a review run of 2.1, the safeguards removed all 432 epithelial cells within 8 iterations, and the run still exited with status 0 (Known issues). A run whose log shows many removals in its first iterations usually needs a smaller time step.
