Mathematics#

Small value types used throughout the solver: vec3 (three-component vector), mat33 (3 x 3 matrix) and quaternion (rotations). eigen_solver.hpp contains a symmetric 3 x 3 eigensolver adapted from the Geometric Tools library (namespace gte); mat33::eigen_decomposition() uses it, for example to find the principal axes of a cell from the covariance matrix of its nodes. The math_modules library is compiled without OpenMP.

Vectors and matrices#

class vec3#

Three-component vector of doubles, used for positions (m), forces (N), momenta and normals.

Components are 0 by default. The constructor and translate() check in debug builds that the components are finite.

Note

Not safe for concurrent updates of the same vector: the math_modules library is compiled without OpenMP, so the atomic pragmas in the implementation have no effect. Use atomic_translate() for shared accumulators.

void translate(const double dx, const double dy, const double dz)#

Add (dx, dy, dz) to this vector in place.

Same thread-safety as translate(const vec3&).

inline void atomic_translate(const vec3 &v) noexcept#

Add v with one atomic read-modify-write per component.

For accumulators that several threads update concurrently, such as the contact forces on a node. The vector as a whole is not updated atomically, which is sufficient for a sum. Uses the GCC/Clang __atomic builtins (a compare-exchange loop) rather than “#pragma omp atomic”, whose effect depends on the translation unit being compiled with -fopenmp; math_modules is built without OpenMP.

Note

Thread-safe with respect to other atomic_translate() calls on the same vector.

class quaternion#

Quaternion w + x i + y j + z k, used to build orthogonal rotation matrices.

The cell divider builds the rotation that maps the division plane onto the xy plane from a normalized quaternion, so that the rotation matrix is orthogonal.

Eigensolver#

template<typename Real>
class SymmetricEigensolver3x3#

Iterative eigensolver for a symmetric 3 x 3 matrix.

Template Parameters:

Real – Floating-point type.

Public Functions

int operator()(Real a00, Real a01, Real a02, Real a11, Real a12, Real a22, bool aggressive, int sortType, std::array<Real, 3> &eval, std::array<std::array<Real, 3>, 3> &evec) const#

Compute the eigenvalues and eigenvectors of the matrix with upper triangle (a00, a01, a02, a11, a12, a22).

Parameters:

  • aggressive – Iterate until a superdiagonal entry is exactly zero (true) or negligible compared to its diagonal neighbours (false).

  • sortType – -1 decreasing, 0 unsorted, +1 increasing eigenvalues.

  • eval – Output eigenvalues.

  • evec – Output eigenvectors; evec[i] belongs to eval[i]. When sorted, they form a right-handed orthonormal set.

Returns:

Number of iterations used.
