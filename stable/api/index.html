API reference#

SimuCell3D is used mainly as the command-line program simucell3d, configured by a parameter file and by the compile-time macros in include/global_configuration.hpp. This reference is for readers who extend the solver in C++ (a new cell class, contact model or output array) or who drive it from Python. Running simulations does not require it; see the User guide.

C++ classes#

The C++ API is the set of headers in include/. All classes are in the global namespace, with two exceptions: the thread-placement functions in the namespace cpu_topology and the eigensolver in the namespace gte. Class names are lower case with underscores (solver, cell, local_mesh_refiner), and data members end with an underscore.

The reference is organised by module, following the subdirectories of include/ and src/:

Each page starts with a short description of the module’s role in the simulation and links to the user-guide chapter that explains the model. The class entries below it list the public members with the comments from the headers. Members that exist only for some values of the compile-time macros (for example only with CONTACT_MODEL_INDEX 1 or 2) are listed whatever the configuration; their comment states the condition.

Note

The class entries are built from the Doxygen comments in include/ when the documentation is published. A local build without Doxygen shows the module descriptions only; see Writing documentation to build the full reference.

Python module#

The optional pybind11 module simucell3d_python_wrapper is documented on its own page, Python module. It runs a complete simulation from Python with parameters set as attributes and returns per-cell statistics and the final cells.
