Solver and configuration#

The solver owns the cells of a simulation and runs the main loop. Its constructor receives the numerical parameters (global_simulation_parameters) and the list of cells built by simulation_initializer, chooses the thread count and placement and the OpenMP schedule, and creates the modules (mesh refiner, contact model, time integrator, statistics writer). solver::run() then calls solver::run_iteration() until the simulation duration is reached or no cell is left. The order of the steps inside one iteration is given in API reference and, in detail, in Main loop; the model is described in Model overview.

The macros in global_configuration.hpp select the contact model, the dynamic model and the polarization mode at compile time (Compile-time configuration). The parameter structures mirror the sections of the parameter file (Parameter file reference). Errors that end a run are reported with the exception classes listed at the end of this page.

Solver#

class solver#

Runs a simulation: owns the cells and the modules that update them at every iteration.

The constructor sets up the thread count and placement, the OpenMP scheduling, the output folder and the modules (local mesh refiner, contact model, time integration scheme, statistics writer). run() then calls run_iteration() until the simulation duration is reached or no cell is left. One iteration writes the output meshes when a new sampling period starts, divides cells (every 5 iterations), updates the face types, refines the meshes, computes the contact forces, updates the polarization, computes the internal forces of each cell (which also advances its target volume), moves the nodes, writes the statistics every 50 iterations and the diagnostics every 100 iterations, and removes dead or numerically unstable cells.

The contact model, dynamic model and polarization mode are fixed at compile time (global_configuration.hpp).

Subclassed by solver_python_wrapper

Public Functions

solver() = default#

Construct an empty solver; use the parameter constructor to run a simulation.

~solver()#

Release the modules of the solver in reverse order of creation.

solver(const global_simulation_parameters &sim_parameters, const std::vector<cell_ptr> &cell_lst, int nb_threads = -1, bool write_cell_stats_in_string = false, bool verbose = true, const std::string &schedule_mode = "adaptive", const std::string &diagnostics_csv_path = "") noexcept(false)#

Set up a simulation.

Chooses the thread count, pins one thread per physical core (unless cpu_topology::pinning_requested() is false), configures the OpenMP scheduling, deletes and re-creates the output folder (with cell_data/, face_data/ and, with POLARIZATION_MODE_INDEX 2, region_data/), assigns cell ids, sets the initial target volumes and creates the modules.

Warning

The output folder is deleted, with all its content, before it is re-created.

Parameters:

  • sim_parameters – Numerical parameters of the simulation.

  • cell_lst – Cells to simulate, as built by simulation_initializer.

  • nb_threads – Number of OpenMP threads; 0 or less uses one thread per physical core.

  • write_cell_stats_in_string – Write the per-cell statistics to a string (read with get_simulation_statistics()) instead of simulation_statistics.csv.

  • verbose – Print the progress of the simulation.

  • schedule_mode – OpenMP scheduling mode: static, dynamic, guided or adaptive.

  • diagnostics_csv_path – Path of the diagnostics CSV; empty for <output folder>/performance_diagnostics.csv.

Throws:

intialization_exception – If the scheduling mode is invalid or the output folders cannot be created.

void run() noexcept(false)#

Run the main loop until the simulation duration is reached or no cell is left.

Calls run_iteration() repeatedly, then writes a last row of statistics and, if verbose, prints the performance report.

Throws:

  • unstable_simulation_exception – If the simulation diverges (see run_iteration()).

  • intialization_exception – If the statistics file cannot be written.

virtual void run_iteration() noexcept(false)#

Run one iteration (one time step) of the simulation.

Virtual so that derived solvers can add work to each iteration (solver_python_wrapper checks for Ctrl-C here).

Throws:

  • unstable_simulation_exception – If too many mesh refinements fail (handle_refinement_failures()) or the contact grid cannot be built for a diverged tissue.

  • intialization_exception – If the statistics file cannot be written.

  • mesh_writer_exception – If an output mesh cannot be written.

void save_mesh() noexcept(false)#

Write the cell and face meshes if a new sampling period has started.

Files are cell_data/result_<n>.vtk and face_data/result_<n>.vtk with n = floor(t / sampling period) + 1 (and region_data/result_<n>.vtk with POLARIZATION_MODE_INDEX 2).

Throws:

mesh_writer_exception – If a file cannot be written.

void remove_dead_cells() noexcept#

Erase the cells below their minimum volume and the numerically unstable ones.

Last step of run_iteration(). Each unstable cell is reported on standard error and counted in get_nb_unstable_cells_removed().

void handle_refinement_failures(const std::vector<local_mesh_refiner::refinement_failure> &failures) noexcept(false)#

Erase the cells whose mesh refinement failed in this iteration.

Called by run_iteration() right after the mesh refinement, before contact detection. Each removed cell is reported on standard error and counted in get_nb_unstable_cells_removed().

Parameters:

failures – Cells reported by local_mesh_refiner::refine_meshes(), with the reason of each failure.

Throws:

unstable_simulation_exception – If there are more failures than refinement_failure_limit() allows (max(10, 1 % of the cells)) or if the failures cover every cell. Nothing is erased then.

Compile-time configuration#

The switches are macros in include/global_configuration.hpp; changing one requires a rebuild (Compile-time configuration).

Macro

Values (default in bold)

CONTACT_MODEL_INDEX

0: springs between nodes and faces of adjacent cells; 1: coupling of pairs of adjacent nodes; 2: coupling of pairs of adjacent faces

DYNAMIC_MODEL_INDEX

0: full equations of motion, semi-implicit Euler; 1: overdamped, forward Euler

POLARIZATION_MODE_INDEX

0: none; 1: from the contacts of the cell; 2: from a discretization of the simulation space

FACE_STORE_CONTACT_ENERGY

false; true stores the adhesion and repulsion energies on each face

WRITE_NORMALS_IN_OUTPUT_MESH_FILE

false; true writes face and node normals in the output meshes

Parameters and results#

enum class ContactDetectionAlgorithm#

Contact detection algorithm, set by the optional contact_detection_algorithm tag of the parameter file.

Values:

enumerator USPG#

Uniform spatial partitioning grid (uspg, default).

enumerator SWEEP_AND_PRUNE#

Sweep and prune on the axis-aligned bounding boxes of the cells (sweep_and_prune).

enumerator ADAPTIVE#

USPG below ADAPTIVE_SAP_CELL_THRESHOLD cells, sweep and prune from that count on (adaptive).

constexpr size_t ADAPTIVE_SAP_CELL_THRESHOLD#

Number of cells from which the adaptive contact detection switches from the USPG to sweep and prune.

struct mesh#

Lightweight polygon mesh used to read cell meshes and to divide cells.

The faces need not be triangles. Layout:

  • face_point_ids = {{f0_n0, f0_n1, f0_n2, f0_n3}, {f1_n0, f1_n1, f1_n2}, ...}, where f0_n1 is the id of the second node of the first face;

  • node_pos_lst = {x0, y0, z0, x1, y1, z1, ...}.

Public Functions

Return the number of nodes.

Public Members
